## 3. Az adatmodell

**Törzsadat — leíró-alapon (k2 `TorzsLeirok`), O3, szinkron mindkét irányban:**

| Tábla | Mezők | Jog |
|---|---|---|
| `modosito_csoport` | név, min, max, ingyenes (FreeLimit), ingyenes sorrend (ELSŐ / LEGDRÁGÁBB / LEGOLCSÓBB), aktív | `modosito.kezeles` |
| `modosito` | csoport, név, típus (HOZZÁADÓ / LEVONÓ), ár (egész Ft; 0 = szövegsor), anyag, anyag mennyisége, legfeljebb db, aktív | 〃 |
| `termek_modosito_csoport` | termék, csoport, min/max/ingyenes felülírás (üres = a csoporté), sorrend, aktív | 〃 |
| `menu_komponens` | a menü kiszerelése, név, min, max, sorrend, aktív | `menu.kezeles` |
| `menu_opcio` | komponens, a választható kiszerelés, felár, sorrend, aktív | 〃 |
| `anyag` + `allergenek` | „?" = ismeretlen, „" = nincs, vagy a kódok | `recept.szerkesztes` |
| `recept` + `allergen_felulir` | „?" = nincs felülírás | 〃 |

**Eladás** *(C1-2)*: a tételsor kap egy `fajta`-t (TETEL / MODOSITO / KEDVEZMENY /
MENU_KOMPONENS), szülőt és menüpéldányt; a módosítók a `tetelsor_modosito`-ban
(szöveg, készlet), az áras hozzáadó gyereksorként, az áras levonó negatív
KEDVEZMENY-gyereksorként.
